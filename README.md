## 🚀 我的项目 · My Projects

### [简包装 · JianPack](https://github.com/kllber/jianpack)

一款面向新手用户的**可视化 Windows 安装包制作工具**（Inno Setup Compiler 的替代方案）。
底层用 **NSIS** 引擎，**生成的安装包零依赖**——对方双击就能装，不需要 .NET、Python 或任何运行时。
界面中英双语，支持浅色 / 深色主题，附带图文教程。

*A beginner-friendly **visual Windows installer builder** (an alternative to Inno Setup Compiler),
powered by **NSIS**. It produces **dependency-free installers** — just double-click, no .NET or Python
runtime needed. Bilingual UI with light / dark themes and a built-in illustrated tutorial.*
